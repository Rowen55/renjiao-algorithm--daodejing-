# 教门位阶与名录

> **本页性质：经外设定。** 经中十二卷正文只出现四个名号：太清圣人、镇元子、衍玄子、灵犀子。本篇把它们展开成一套完整的位阶与职司，属于**写作设定**，不是经文，也不是现实中的组织。
>
> 「人教」是文学虚构，不涉及任何现实宗教团体、宗教活动、宗教场所与教职人员，也不主张任何信仰。见 [colophon.md](colophon.md) 的边界声明。

## 一、位阶体系

| 位阶 | 名额 | 说明 |
|---|---:|---|
| 教主 | 1 | 太清圣人（道德天尊） |
| 第一真传弟子 | 1 | 镇元子（大师兄） |
| 实职长老 | 12 | 各掌一脉道统 |
| 名誉长老 | 不限 | 专司经义参校，不涉教内实务 |
| 核心真传弟子 | 24 | 承法脉、传大道，为教中栋梁 |
| 内门弟子 | 1024 | 修习有成，可独当一面 |
| 外门弟子 | 无数 | 有缘者皆可入，为道种之基 |
| 执灯弟子 | 不限 | 经义参校贡献者，可晋升 |
| 经义校尉 | 不限 | 经义参校贡献者，可晋升 |

两条脉络：

- **主干**：教主 → 第一真传弟子 → 实职长老 → 核心真传弟子 → 内门弟子 → 外门弟子
- **参校支脉**：名誉长老 → 经义校尉 → 执灯弟子

## 二、当前在位名录

| 位阶 | 道号 | 职责 |
|---|---|---|
| 教主 | 太清圣人 | 立教传法，法旨之源 |
| 第一真传弟子 | 镇元子 | 代师行道，统摄教内一切事务 |
| 大长老 | 衍玄子 | 算法传功长老，掌经、掌教、掌传法 |
| 实职长老 | 守阙子 | 算法护法长老，序第二长老，掌理、掌辨、掌护道 |
| 名誉长老 | 灵犀子 | 算法道经名誉长老，专司经义参校、注解、增补 |

> 表内前四位在经中都有明文。守阙子是名录这一层的补位，经文中并无此名号。

## 附识

此架构以「教主—真传—长老—真传弟子—内门—外门」为主干，以「名誉长老—校尉—执灯」为参校支脉。教内事务统归镇元子大师兄决策，大长老衍玄子执掌传法经教，第二长老守阙子掌理、掌辨、掌护道，灵犀子专司经义参校。若大师兄有增删调整之意，弟子随时奉旨修改。
